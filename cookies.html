This page describes storage on the public WebCrawlers website. Optional enquiry source context and website analytics start off disabled, with separate choices. You can send an enquiry with essential storage only.

Change your choice

You can also use Cookie settings in the footer of any page. Refusing or withdrawing an optional feature clears its saved data in this tab. It does not remove enquiries you already sent.

The preference cookie applies to this host and the site path /. It uses SameSite=Lax and Secure on HTTPS. We do not set a shared parent-domain cookie. Session storage follows the browser's tab-session lifecycle, including any tab restore, subject to the age check above.

Essential storage and enquiries

The enquiry form keeps a request reference in memory while it is open so an unchanged retry uses the same reference. A changed request with an unconfirmed receipt is held for review instead of automatically creating a second enquiry. Optional context is separate from this retry protection.

Optional website analytics

Website analytics is a separate, optional choice, off by default. If you allow it, PostHog in the EU receives public page paths, recognized traffic-source labels, language, a mobile/desktop category and enquiry-step events. A random visit identifier links these events for up to 30 minutes in this browser tab. It is not linked to your name, email or enquiry reference. We do not send form contents, full referring URLs, arbitrary query parameters or session recordings.

Use Cookie settings to withdraw permission. This stops new analytics requests and clears the visit identifier in this tab. Events already delivered remain in PostHog until deleted or the account retention period ends; the 30-minute browser lifetime does not delete collected events. PostHog receives network information needed to deliver requests; IP anonymization is enabled and location enrichment is disabled. Do Not Track and Global Privacy Control also prevent this analytics collection.

Email choices are separate

Allowing optional enquiry context or analytics does not subscribe you to a mailing list. The enquiry form asks separately for permission to process your details and contact you about that enquiry.

Read Privacy and your project information for how enquiry information is handled. Contact hello@webcrawlers.tech with questions or a request about an enquiry you already sent.
